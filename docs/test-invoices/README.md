补充人工/界面回归点：

- `上传发票` 与 `上传行程单` 为分开的 tab 和按钮，不做混传自动分类。
- 上传发票结果列表显示关联发票号码。
- 行程单列表显示关联发票号码；未关联显示 `-`。
- 发票行内 `上传凭证`、`关联凭证`、`解除凭证` 只维护关系，不删除行程单文件。
- 行程单 tab 可以删除未被使用的行程单；已被发票使用的行程单前后端都应阻止删除。
- 费用明细 `说明/description` 不由 OCR 机填，仅允许用户手工维护。
